## ブラウザ IDE・サンドボックス

### Replit
共同編集可能なブラウザベースの IDE とアプリビルダー。ローカル環境のセットアップなしで多くの言語を扱える。

- https://replit.com/

### StackBlitz
ブラウザ上の即時フルスタック Web 環境（WebContainers）。フロントエンド／Node の試作に便利。

- https://stackblitz.com/

### CodeSandbox
ライブプレビュー、テンプレート、共同編集付きのオンラインコードサンドボックス — React や Web アプリに強い。

- https://codesandbox.io/

### CodePen
HTML、CSS、JavaScript のフロントエンド向けプレイグラウンド。デモや UI 実験向き。

- https://codepen.io/

### JS Bin
ライブな HTML/CSS/JS 出力付きの共同 JavaScript デバッグ環境。

- https://jsbin.com/?html,output

## 言語プレイグラウンド

### SharpLab
.NET 言語プレイグラウンド — C# / IL / JIT / 逆コンパイルを並べて確認できる。

- https://sharplab.io/
- https://github.com/ashmind/SharpLab

### Rust Playground
公式の Rust プレイグラウンド — ブラウザで Rust をコンパイル・実行。

- https://play.rust-lang.org/

### Go Playground
公式の Go プレイグラウンド（正規 URL は現在 go.dev 上）。

- https://go.dev/play/

### TypeScript Playground
公式の TypeScript プレイグラウンド — 型、コンパイラオプション、出力 JS を探索できる。

- https://www.typescriptlang.org/play/

### Kotlin Playground
公式の Kotlin プレイグラウンド — Kotlin のスニペットをオンラインで試せる。

- https://play.kotlinlang.org/

### Compiler Explorer (Godbolt)
多数の言語・コンパイラにわたるコンパイラ出力（asm、IR、最適化）を探索できる。

- https://godbolt.org/

### 3v4l
オンライン PHP エディタ — 250 以上の PHP バージョンでコードを試せる。

- https://3v4l.org/

### Google Colab
Colaboratory — ブラウザ上の Python ノートブック（ML／データ作業に便利）。

- https://colab.research.google.com/

## コンバータ・データツール

### JSON to C#
Json2CSharp Toolkit — JSON サンプルから C# クラスをオンラインで生成。

- https://json2csharp.com/

### quicktype
JSON から型とシリアライザを生成（TypeScript、Go、Rust、Python、C# など）。

- https://quicktype.io/

### transform.tools
コード変換ツール — JSON → TypeScript、SVG → JSX、CSS → Tailwind など。

- https://transform.tools/

### CyberChef
「サイバー・スイスアーミーナイフ」— エンコード／デコード、ハッシュ、圧縮、パース、操作の連鎖をクライアント側で実行。

- https://gchq.github.io/CyberChef/

### jwt.io
JSON Web Token をデコードして検査（ヘッダ／ペイロード／署名）。

- https://jwt.io/

### Hoppscotch
ブラウザ上のオープンソース API クライアント — REST、GraphQL、WebSocket など（Postman の代替）。

- https://hoppscotch.io/

## 正規表現

### regex101
正規表現の作成、テスト、デバッグ。QUICK REFERENCE が便利。

- https://regex101.com/

### RegExr
ライブハイライトとコミュニティパターン付きで RegEx を学び、作り、テストできる。

- https://regexr.com/

## 数式・ダイアグラム

### HostMath
オンライン LaTeX 数式エディタ／ブラウザベースの数式エディタ。

- https://www.hostmath.com/
- https://www.hostmath.com/Demo.aspx

### Mermaid Live Editor
Mermaid ダイアグラム（フローチャート、シーケンス、ER など）をブラウザで編集・プレビュー。

- https://mermaid.live/

### Excalidraw
手書き風のホワイトボード。ダイアグラムやスケッチ用で、共有リンクあり。

- https://excalidraw.com/

### Carbon
ドキュメントや SNS 向けに、ソースコードのきれいなスクリーンショットを作成。

- https://carbon.now.sh/

## 画像ツール

### Squoosh
画像圧縮 Web アプリ — ブラウザ内でローカルにリサイズ／エンコード（プライバシーに配慮）。

- https://squoosh.app/

### Photopea
ブラウザで動く高機能オンライン写真エディタ（PSD 対応）。

- https://www.photopea.com/
