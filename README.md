# awesome-online-services

[日本語版はこちら / Japanese](README.ja.md)

Useful online developer services — browser IDEs, language playgrounds, converters, regex, image tools, TTS, and more.

⭐ badges show live GitHub star counts (via shields.io).

## Browser IDEs & sandboxes

### Replit
Collaborative browser-based IDE that has evolved into an AI app builder (Replit Agent). Code in many languages without local setup; free Starter plan available.

- https://replit.com/

### StackBlitz
Instant full-stack web environments in the browser (WebContainers). Great for frontend/Node prototypes. The same team also runs the AI app builder Bolt.new.

- https://stackblitz.com/
- https://bolt.new/

### CodeSandbox
Online code sandbox with live preview, templates, and collaboration — strong for React and web apps. Now part of Together AI and also offers the CodeSandbox SDK for running AI-agent sandboxes.

- https://codesandbox.io/

### CodePen
HTML, CSS, and JavaScript front-end playground for demos and UI experiments. CodePen 2.0 adds a new editor with multiple files, a built-in compiler, and deployment.

- https://codepen.io/

### JS Bin
Collaborative JavaScript debugging with live HTML/CSS/JS output. Open source but minimally maintained (last code push mid-2025); the hosted site can be intermittently unavailable.

- https://jsbin.com/?html,output
- https://github.com/jsbin/jsbin ![GitHub stars](https://img.shields.io/github/stars/jsbin/jsbin?style=flat&label=%E2%AD%90)

## Language playgrounds

### SharpLab
.NET language playground — see C# / IL / JIT / decompilation side by side.

- https://sharplab.io/
- https://github.com/ashmind/SharpLab ![GitHub stars](https://img.shields.io/github/stars/ashmind/SharpLab?style=flat&label=%E2%AD%90)

### Rust Playground
Official Rust playground — compile and run Rust in the browser.

- https://play.rust-lang.org/
- https://github.com/rust-lang/rust-playground ![GitHub stars](https://img.shields.io/github/stars/rust-lang/rust-playground?style=flat&label=%E2%AD%90)

### Go Playground
Official Go playground (canonical URL is now on go.dev).

- https://go.dev/play/

### TypeScript Playground
Official TypeScript playground — explore types, compiler options, and emitted JS.

- https://www.typescriptlang.org/play/

### Kotlin Playground
Official Kotlin playground — try Kotlin snippets online.

- https://play.kotlinlang.org/

### Compiler Explorer (Godbolt)
Explore compiler output (asm, IR, optimizations) across many languages and compilers.

- https://godbolt.org/
- https://github.com/compiler-explorer/compiler-explorer ![GitHub stars](https://img.shields.io/github/stars/compiler-explorer/compiler-explorer?style=flat&label=%E2%AD%90)

### 3v4l
Online PHP editor — test code across 500+ PHP versions.

- https://3v4l.org/

### Google Colab
Colaboratory — Python notebooks in the browser (great for ML / data work).

- https://colab.research.google.com/

### JupyterLite
WebAssembly-powered Jupyter that runs entirely in the browser — no server or sign-in needed (Project Jupyter).

- https://jupyter.org/try-jupyter/lab/
- https://github.com/jupyterlite/jupyterlite ![GitHub stars](https://img.shields.io/github/stars/jupyterlite/jupyterlite?style=flat&label=%E2%AD%90)

## Converters & data tools

### JSON to C#
Json2CSharp Toolkit — convert JSON samples to C# classes online (also Java, Python, Dart).

- https://json2csharp.com/

### quicktype
Generate types and serializers from JSON (TypeScript, Go, Rust, Python, C#, and more). Also offers an MCP server for AI agents.

- https://quicktype.io/
- https://github.com/glideapps/quicktype ![GitHub stars](https://img.shields.io/github/stars/glideapps/quicktype?style=flat&label=%E2%AD%90)

### transform.tools
Code transformers — JSON → TypeScript, SVG → JSX, CSS → Tailwind, and more.

- https://transform.tools/
- https://github.com/ritz078/transform ![GitHub stars](https://img.shields.io/github/stars/ritz078/transform?style=flat&label=%E2%AD%90)

### CyberChef
“Cyber Swiss Army Knife” — encode/decode, hash, compress, parse, and chain operations client-side.

- https://gchq.github.io/CyberChef/
- https://github.com/gchq/CyberChef ![GitHub stars](https://img.shields.io/github/stars/gchq/CyberChef?style=flat&label=%E2%AD%90)

### IT Tools
Open-source collection of handy developer utilities (UUID/hash generators, converters, encoders, network calculators, and more); self-hostable via Docker.

- https://it-tools.tech/
- https://github.com/CorentinTh/it-tools ![GitHub stars](https://img.shields.io/github/stars/CorentinTh/it-tools?style=flat&label=%E2%AD%90)

### jwt.io
Decode and inspect JSON Web Tokens (header / payload / signature). Run by Auth0 (Okta).

- https://jwt.io/

### Hoppscotch
Open-source API client in the browser — REST, GraphQL, WebSocket, and more (Postman alternative).

- https://hoppscotch.io/
- https://github.com/hoppscotch/hoppscotch ![GitHub stars](https://img.shields.io/github/stars/hoppscotch/hoppscotch?style=flat&label=%E2%AD%90)

### JSON Crack
Visualize JSON, YAML, XML, and CSV as interactive graphs in the browser (open source; premium features moved to ToDiagram).

- https://jsoncrack.com/
- https://github.com/AykutSarac/jsoncrack.com ![GitHub stars](https://img.shields.io/github/stars/AykutSarac/jsoncrack.com?style=flat&label=%E2%AD%90)

### crontab.guru
Quick and simple editor for cron schedule expressions, with a plain-English explanation (by Cronitor).

- https://crontab.guru/
