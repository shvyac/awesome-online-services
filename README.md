# awesome-online-services

Useful online developer services — browser IDEs, language playgrounds, converters, regex, image tools, TTS, and more.

## Browser IDEs & sandboxes

### Replit
Collaborative browser-based IDE and app builder. Code in many languages without local setup.

- https://replit.com/

### StackBlitz
Instant full-stack web environments in the browser (WebContainers). Great for frontend/Node prototypes.

- https://stackblitz.com/

### CodeSandbox
Online code sandbox with live preview, templates, and collaboration — strong for React and web apps.

- https://codesandbox.io/

### CodePen
HTML, CSS, and JavaScript front-end playground for demos and UI experiments.

- https://codepen.io/

### JS Bin
Collaborative JavaScript debugging with live HTML/CSS/JS output.

- https://jsbin.com/?html,output

## Language playgrounds

### SharpLab
.NET language playground — see C# / IL / JIT / decompilation side by side.

- https://sharplab.io/
- https://github.com/ashmind/SharpLab

### Rust Playground
Official Rust playground — compile and run Rust in the browser.

- https://play.rust-lang.org/

### Go Playground
Official Go playground (canonical URL is now on go.dev).

- https://go.dev/play/

### TypeScript Playground
Official TypeScript playground — explore types, compiler options, and emitted JS.

- https://www.typescriptlang.org/play/

### Kotlin Playground
Official Kotlin playground — try Kotlin snippets online.

- https://play.kotlinlang.org/

### Compiler Explorer (Godbolt)
Explore compiler output (asm, IR, optimizations) across many languages and compilers.

- https://godbolt.org/

### 3v4l
Online PHP editor — test code across 250+ PHP versions.

- https://3v4l.org/

### Google Colab
Colaboratory — Python notebooks in the browser (great for ML / data work).

- https://colab.research.google.com/

## Converters & data tools

### JSON to C#
Json2CSharp Toolkit — convert JSON samples to C# classes online.

- https://json2csharp.com/

### quicktype
Generate types and serializers from JSON (TypeScript, Go, Rust, Python, C#, and more).

- https://quicktype.io/

### transform.tools
Code transformers — JSON → TypeScript, SVG → JSX, CSS → Tailwind, and more.

- https://transform.tools/

### CyberChef
“Cyber Swiss Army Knife” — encode/decode, hash, compress, parse, and chain operations client-side.

- https://gchq.github.io/CyberChef/

### jwt.io
Decode and inspect JSON Web Tokens (header / payload / signature).

- https://jwt.io/

### Hoppscotch
Open-source API client in the browser — REST, GraphQL, WebSocket, and more (Postman alternative).

- https://hoppscotch.io/

## Regex

### regex101
Build, test, and debug regular expressions. QUICK REFERENCE が便利。

- https://regex101.com/

### RegExr
Learn, build, and test RegEx with live highlighting and community patterns.

- https://regexr.com/

## Math & diagrams

### HostMath
Online LaTeX formula editor and browser-based math equation editor.

- https://www.hostmath.com/
- https://www.hostmath.com/Demo.aspx

### Mermaid Live Editor
Edit and preview Mermaid diagrams (flowcharts, sequence, ER, etc.) in the browser.

- https://mermaid.live/

### Excalidraw
Hand-drawn style whiteboard for diagrams and sketches — shareable links.

- https://excalidraw.com/

### Carbon
Create pretty screenshots of source code for docs and social posts.

- https://carbon.now.sh/

## Image tools

### Squoosh
Image compression web app — resize/encode locally in the browser (privacy-friendly).

- https://squoosh.app/

### Photopea
Full-featured online photo editor (PSD-friendly) that runs in the browser.

- https://www.photopea.com/
